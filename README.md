# hadaway-seller-finance

Marketing campaign for 1244 Hadaway Ct NE, Lawrenceville GA 30043 (seller-financed sale).

**Live page:** https://theluckystrike.github.io/hadaway-seller-finance/

## Structure
- `site/index.html` — landing page source (mirrored to `docs/` for GitHub Pages)
- `data/property.json` — property facts, comps, listing history
- `data/finance-model.json` — seller-finance scenarios ($15K-$30K down, 8.5%, 5-yr balloon)
- `data/personas.json` — buyer personas (credit-impaired, self-employed, house-hackers, note buyers)
- `data/channel-plan.json` — ranked channels with effort/velocity
- `data/ad-copy.json` — ready-to-paste ad copy + objection handling + daily checklist
- `data/leads.csv` — lead tracker (log every lead: date,source,contact,channel,status,notes)

## Deployment
GitHub Pages serves from `docs/` on main. Edit `site/index.html`, copy to `docs/`, push.
